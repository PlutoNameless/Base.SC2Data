# Как добавить кастомного юнита на вашу карту

Это руководство объясняет, как интегрировать юнита из **Tal'darim Forces Data Library** в вашу карту StarCraft II.

---

## Что понадобится

- Скачайте актуальный архив с библиотекой данных:  
  https://www.curseforge.com/sc2/assets/data-library-taldarim-forces/files/7876212
- Откройте вашу карту в редакторе SC2.

---

## Шаг 1 — Разобрать карту на компоненты

1. В редакторе SC2 выберите **Файл → Сохранить как...**
2. В окне сохранения укажите тип файла **«StarCraft II Папка компонентов»**.
3. Дайте имя, **отличное** от названия оригинальной карты, и сохраните.

> Это создаст папку с файлами карты, в которой можно свободно добавлять и редактировать данные.

## Шаг 2 — Открыть папку компонентов

Перейдите в папку, которую вы только что сохранили. Это корневая папка вашей карты — все дальнейшие шаги выполняются внутри неё.

## Шаг 3 — Скопировать все XML-файлы из архива юнита

Каждый архив юнита **самодостаточен** — помимо самого файла юнита, в него уже включены все необходимые базовые файлы (`base.xml`, `protoss.xml`, `terran.xml`, `zerg.xml`). Это сделано для того, чтобы обновления базовых файлов не сломали уже добавленных юнитов.

Внутри папки карты перейдите по пути `Base.SC2Data/GameData/`.  
Скопируйте **все** `.xml`-файлы из архива юнита в эту папку.

> Можно сохранить структуру папок из архива (например, `GameData/Taldarim/Ascendant/Ascendant.xml`).

Какие именно базовые файлы нужны конкретному юниту, можно посмотреть в строках `<!-- Requires: -->` в начале его XML-файла:

```xml
<!-- Requires: Unit:Generic_Unit_Ground[base.xml] -->
<!-- Requires: DataCollectionUnit:Weapon_Base[base.xml] -->
```

Имя файла в квадратных скобках (здесь `base.xml`) — это нужный базовый файл. Все они уже лежат в архиве.

> **Важно:** если вы добавляете нескольких юнитов, и их архивы содержат базовые файлы с одинаковыми именами, используйте версию из архива того юнита, который вы добавляете последним. Базовые файлы разных юнитов совместимы между собой, но могут отличаться версией.

## Шаг 4 — Зарегистрировать файлы в GameData.xml

Внутри папки `Base.SC2Data/` создайте (или отредактируйте) файл `GameData.xml`. Добавьте строку `<Catalog>` для каждого скопированного файла — и базовых, и файла юнита:

```xml
<?xml version="1.0" encoding="utf-8"?>
<Includes>
    <Catalog path="GameData/base.xml"/>
    <Catalog path="GameData/protoss.xml"/>
    <Catalog path="GameData/terran.xml"/>
    <Catalog path="GameData/zerg.xml"/>
    <Catalog path="GameData/Taldarim/Ascendant/Ascendant.xml"/>
</Includes>
```

> Замените последний путь на фактический путь к XML-файлу вашего юнита.  
> Указывайте только те базовые файлы, которые вы реально скопировали — не все юниты требуют все четыре.

## Шаг 5 — Скопировать папки Assets

Скопируйте все папки `Assets` из архива в **корень** папки вашей карты.  
В них содержатся 3D-модели, текстуры и звуки, используемые юнитом.

## Шаг 6 — Объединить файлы локализации

Откройте файлы локализации из архива (например, `ruRU.SC2Data/GameStrings.txt`) и скопируйте их содержимое в соответствующие файлы вашей карты:

| Файл из архива | Файл в вашей карте |
|---|---|
| `ruRU.SC2Data/GameStrings.txt` | `ruRU.SC2Data/LocalizedData/GameStrings.txt` |
| `enUS.SC2Data/GameStrings.txt` | `enUS.SC2Data/LocalizedData/GameStrings.txt` |

> Если в вашей карте таких файлов ещё нет — создайте их.

## Шаг 7 — Скопировать локализованные папки ассетов

Скопируйте локализованные папки ассетов (например, `ruRU.SC2Assets`, `enUS.SC2Assets`) из архива в **корень** папки вашей карты.

---

## Краткий чек-лист

- [ ] Карта разобрана на папку компонентов
- [ ] Все XML-файлы из архива юнита (включая базовые) скопированы в `Base.SC2Data/GameData/`
- [ ] Все файлы зарегистрированы в `Base.SC2Data/GameData.xml`
- [ ] Необходимые папки `Assets` скопированы в корень карты
- [ ] Текст локализации добавлен в `GameStrings.txt`
- [ ] Локализованные папки (`*.SC2Assets`) скопированы в корень карты
